## Project Overview

Velocity is a mission-critical enterprise platform for US healthcare insurance and benefits administration, managing dental, health, vision, and HCSA claims processing at enterprise scale.

The role focused on developing auto-adjudication rules engines, high-throughput REST APIs, automated financial batch jobs, and solving complex production incidents.

## Engineering Highlights

- **Claims Auto-Adjudication:** Architected adjudication workflows and validation rules engines on the Vitech Velocity platform, enabling automated decisioning and eligibility verification.
- **Microservices & API Suite:** Built Spring Boot REST APIs for Member Balance inquiries, Claim Submissions, Group benefit configurations, and Plan management.
- **Batch Processing & Document Automation:** Implemented robust scheduled batch processing pipelines for financial disbursements, premium reconciliations, and automated Explanation of Benefits (EOB) PDF generation.
- **Production Incident RCA:** Led root-cause analysis (RCA) for mission-critical incidents, diagnosing JVM OutOfMemoryError issues, thread deadlocks, and database transaction bottlenecks.

## Key Outcomes

- Increased automated claim adjudication rate, reducing manual examiner intervention by over 35%.
- Streamlined daily overnight batch cycles, reducing execution windows by 40%.
